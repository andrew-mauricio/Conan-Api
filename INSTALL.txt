HOW TO INSTALL — read these 20 lines before copying anything
=============================================================

(Este arquivo em portugues: INSTALAR.pt.txt)

You have two things here:

    winmm.dll     <- the loader. WITHOUT IT NOTHING WORKS.
    Conan-Api/    <- the API, the plugins and the documentation

STEP 1 — stop the server.

STEP 2 — go to the folder holding the server executable:
    <server>/ConanSandbox/Binaries/Win64/

STEP 3 — rename the winmm.dll THAT IS ALREADY THERE (the system one) to:
    winmm_orig.dll

    If a winmm_orig.dll already exists, STOP: you installed before. Renaming
    again chains the loader onto itself and the server dies in silence (no log,
    no error, exit 1). Delete only the new winmm.dll and start again from this
    step.

STEP 4 — copy into that same folder:
    winmm.dll     (the loader, the one that came here)
    Conan-Api/    (the whole folder)

STEP 5 — start the server and check:
    Conan-Api/Logs/ConanLoader.log   <- says whether the loader got in
    Conan-Api/Logs/ConanApi.log      <- says which plugins loaded

If the logs are not created, the loader did not get in: go back to step 3.

INSTALLING A PLUGIN YOU DOWNLOADED
===================================

Each plugin comes in a folder. Drag the whole folder into:

    Conan-Api\Plugins\

That is all. Nothing to edit, nothing to enable. Restart the server and it
loads.

It ends up like this:

    Conan-Api\
       Plugins\
          Permission\           <- ships with it, it is the standard one
             ConanPermission.dll
             config.json
          PluginYouDownloaded\  <- the folder you dragged in
             PluginYouDownloaded.dll
             config.json

To UNINSTALL: delete the plugin's folder. That is it.

To DISABLE without deleting (to test whether it is the cause of something):
create an empty file called DESLIGADO inside its folder.

If a plugin does not load, Conan-Api\Logs\ConanLoader.log says why, naming the
folder. The log's own messages are in Portuguese.

The full documentation is in Conan-Api/Docs/GETTING-STARTED.md
